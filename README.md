# wellsIDEA - Startup Problem Discovery Directory

A highly visual, neo-brutalist directory of startup problem-discovery platforms. 

This project is a React/Vite frontend application that acts as a curated list of platforms where entrepreneurs can discover real customer pain points before building solutions.

## Features
- **Editorial Bento Grid:** A dynamic 3-column asymmetric layout with a tactile, die-cut card feel.
- **Physical Micro-interactions:** Magnetic cursor effects, 3D tilts, spring-based hovering, and offset hard shadows.
- **Today's Discovery:** An oversized spotlight banner that dynamically recommends a platform based on the current day of the year.
- **Neo-brutalist Design System:** Warm cream background, sunny yellow, cobalt blue, and candy pink palettes combined with thick ink borders.
- **Frontend Only:** Pure static experience powered by Framer Motion, Tailwind CSS v4, and Lucide React.

## Getting Started

1. Navigate to the project directory:
   ```bash
   cd startup-problems-directory
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Tech Stack
- React 18
- Vite
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Design Inspiration
Inspired by tactile physical cards, stickers, and editorial magazine layouts. Built to be playful, fast, and satisfying to interact with.
